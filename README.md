# 動畫旁白對位器

純前端 HTML 工具，協助將每個場景的錄音與動畫字幕對位。入口為 `index.html`，無需安裝套件或後端伺服器。

## 在網上使用

本儲存庫已包含網站入口，但上傳程式不等於已開啟 GitHub Pages。
請登入 GitHub，進入本儲存庫的 **Settings → Pages**，在 **Build and deployment** 選擇：
- Source：Deploy from a branch
- Branch：main
- Folder：/ (root)
- 按 Save，等待 GitHub 完成部署；以 Pages 頁顯示的網站連結為準。

## 使用流程

1. 選擇動畫 HTML（支援工具能辨識的 GSAP 單一時間軸或 registerScene／TIMING 格式）。
2. 選擇每個場景的 MP3、M4A 或 WAV，核對檔案順序。
3. 檢查分句並逐句試聽；偵測停頓並不等同語音辨識。
4. 匯出內嵌錄音的 HTML，再由頭播放核對。

工具本身不會上傳選取的檔案。匯出動畫原有的外部字型、圖片、GSAP 等仍可能需要網絡。
瀏覽器支援的音訊編碼各有不同。大型音檔會消耗較多記憶體。

## 本次修正

- 不完整的 registerScene／TIMING 輸入能顯示錯誤訊息。
- 部分音檔無法讀取時，字幕索引不會錯位或導致當機。
- 手動開始／結束時間須在錄音範圍內。
- 沒有偵測到有效聲音時阻止匯出。
- 匯出按鈕實際停用，並在產生檔案前再次驗證。
- 避免將未處理的音檔名稱放入匯出 JavaScript 註解。

